# lifeprismevalue 术语表

本模块的通用语言。代码注释、文档、评测用例提到这些词时，指的应是同一件事。
一个词只在**能正确使用**之后才收录；定义一两句，说清「是什么」，不说「怎么用」。

## 时间

**运行时长（耗时）**：
被测评 agent 从开始到结束的墙上时钟间隔。由用例在跑之前与跑完之后各打一个点算得，
是 `summary.csv` 里「耗时(s)」列的唯一口径，也是唯一代表「这次跑了多久」的量。
_避免_：总 step 耗时、LLM 耗时、总耗时

**起止打点**：
量运行时长的那两个时刻。起点打在环境准备（基线快照、precondition、用例快照）**之后**，
终点打在被测评 agent 收尾之后、取证与判定**之前**——所以取证、裁判、统计这三段的耗时都不计入。
_避免_：run 的起止时间（那是整个 run，记在 `run.json`）

**step 耗时**：
单个 step 从开始到结束的耗时，由 `TimingStats` 采集。
_避免_：运行时长

**LLM 耗时**：
单个 step 里模型那一部分的时间，从 step 开始算到流式输出落点。
_避免_：运行时长

**首 token 延迟**：
单个 step 里从 step 开始到第一个流式片段到达的时间，回答「模型多久才开始吐字」。
_避免_：LLM 耗时（那是整段流式输出的总时长）

**工具耗时**：
单个 step 里各工具调用耗时的累加，取自工具结果中记录的耗时字段。
_避免_：LLM 耗时

**时间戳**：
系统记录时刻的统一格式：UTC 时区的 ISO 8601。跨进程、跨机器比较时不带本地时区歧义。
_避免_：本地时间

**时间窗归因**：
按「会话起止时间」从库里捞本次写入的旧做法。
**本仓库不使用**：归因一律靠与环境基线对比（表按 id 比，文件比 diff）。
时间戳照常记录，但只当参照，不参与判定。
_避免_：以为「记了起止时间就是在用时间窗」

### 两个容易混的量

| 说法 | 是什么 | 数值关系 |
| --- | --- | --- |
| **运行时长** | 墙上时钟，起止打点之间 | **较大** |
| **总 step 耗时** | 各 step 耗时之和（`TimingStats`） | **较小** |

两者**必然不等**，差额是 step 之外的开销：建 agent、发送消息、收尾、以及 step 之间的空隙。
实测一条用例：总 step 耗时 16.2s，运行时长 18.0s。
**差值是正常的，不代表采集丢了数据**——拿它当异常去查，会白查。
